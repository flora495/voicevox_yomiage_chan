# VOICEVOX読み上げちゃん

## ローカル設定手順
1. VOICEVOXをインストール(HTTP APIが`localhost:50021`で動いている必要がある)。
1. ffmpeg(PATHも通す)
1. `pip install pynacl`
1. pass.jsonにAPIトークンとユーザーIDを追加（discordで、開発者モードの状態で、ユーザを右クリックすると取得可能）

```
{
  "DISCORD_TOKEN": "ここにBotトークン",
  "TARGET_USER_IDS": [123456789012345678]
}
```
pass.jsonはgithubにアップロードしないこと。手動で作成必要。

## Bot設定
1. Botをサーバーに招待し、`connect`,`speak`の権限を付与する。

## 使い方

1. VOICEVOXを起動
1. src/bot.pyを起動（discord上でオンラインになる）
1. VCに先に参加し、!joinコマンドでbotをVCに参加させる。
1. TARGET_USER_IDSに追加したユーザーが発言すると、自動で読み上げる。

## その他のコマンド

| コマンド          | 説明                                                             |
| ------------- | -------------------------------------------------------------- |
| !join         | 実行者が参加しているボイスチャンネルにBotが参加する。                                   |
| !disconnect        | Botが現在のボイスチャンネルから切断する。                                         |
| !speaker| 対応しているキャラクターの一覧を表示|
| !speaker <名前> | 自分の読み上げキャラを変更する（例: !speaker ずんだもん）。|
| !help         | 利用可能なコマンド一覧と簡単な説明を表示する。                                        |

## その他機能
1. 一定期間(60分)誰も操作しないなら、自動的にオフラインになります。
